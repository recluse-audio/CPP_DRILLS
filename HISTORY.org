* Origin
  - Bjarne Stroustrup started work on what became C++ in 1979
    [[https://www.stroustrup.com/bs_faq.html][Stroustrup FAQ: When was C++ invented?]].
  - The initial version was called C with Classes
    [[https://www.stroustrup.com/bs_faq.html][Stroustrup FAQ: When was C++ invented?]].
  - The first version of C++ was used internally in AT&T in August 1983
    [[https://www.stroustrup.com/bs_faq.html][Stroustrup FAQ: When was C++ invented?]].
  - The first commercial implementation was released in October 1985
    [[https://www.stroustrup.com/bs_faq.html][Stroustrup FAQ: When was C++ invented?]].

* Design goals
  - Stroustrup wanted to write efficient systems programs in the styles encouraged by Simula67
    [[https://www.stroustrup.com/bs_faq.html][Stroustrup FAQ: Why did you invent C++?]].
  - The tasks that started the design had to do with distributing operating system facilities across a network
    [[https://www.stroustrup.com/bs_faq.html][Stroustrup FAQ: Why did you invent C++?]].
