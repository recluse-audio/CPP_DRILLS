* SPECIFICATION
  - =count_words(text)= in =SOURCE/WordCounter.cpp= splits the text on whitespace and returns a
    =std::map<std::string, int>= from each word to its count
  - =sort_words_by_count(counts)= returns a =std::vector<WordCount>= with the highest count first
    - words with the same count are in dictionary order
    - it sorts with =std::sort()= and the named function =compare_word_counts()=
  - =check_word_listed(words, word)= returns =true= when =std::find()= locates the word in a
    =std::vector<std::string>=
  - =SOURCE/main.cpp= reads all of standard input and prints one line per word: the count then the word
