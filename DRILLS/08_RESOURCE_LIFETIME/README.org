* SPECIFICATION
  The problem text RD wrote is in =ATTEMPT_1/README.org=. This drill adds copy and move to it.
  - class =DynamicArray= in =SOURCE/DynamicArray.cpp= owns one heap-allocated =int= array
  - =DynamicArray(int size)= allocates with =new int[size]()=. Every element starts at 0
  - =~DynamicArray()= frees with =delete[]=
  - =addElement(index, value)= stores a value. An index outside the array throws =std::out_of_range=
  - =getElement(index)= returns a value. An index outside the array throws =std::out_of_range=
  - =getSize()= returns the element count
  - =printArray()= prints the elements on one line with one space between them
  - the copy constructor and the copy assignment operator allocate a second array and copy every element
  - the move constructor and the move assignment operator take the pointer. The source is left with size 0

* DECISIONS
  - =make test= builds with =-fsanitize=address=. A missing =delete[]= or a double =delete[]= fails the test run
