* SPECIFICATION
  Two programs. Each reads one line from standard input.
  - =SOURCE/string_reverse.cpp= prints the line reversed and exits 0
  - =SOURCE/string_calculator.cpp= reads a line of the form =<number> <operator> <number>=
    - the operator is one of =+ - * /=
    - it prints the result and exits 0
    - malformed input prints an error to standard error and exits nonzero
    - division by zero prints an error to standard error and exits nonzero
  - =SOURCE/LineTools.cpp= has =reverse_line(line)= and =calculate_line(line)=
    - =calculate_line()= throws =std::invalid_argument= for malformed input
    - =calculate_line()= throws =std::domain_error= for division by zero
