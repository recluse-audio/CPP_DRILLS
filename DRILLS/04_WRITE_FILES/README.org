* SPECIFICATION
  - =SOURCE/write_files.cpp <dir>= writes three records into =<dir>=: =alice 3= and =bob 5= and =carol 8=
  - each record is a name and an integer
  - =records.txt= has one record per line. One space separates name and number
  - =records.csv= has a =name,number= header row then one row per record. Lines end in =\n=
  - =records.json= is an array of objects with keys =name= and =number= at an indent of 4 spaces
  - it exits 0
  - a missing =<dir>= argument prints a usage line to standard error and exits nonzero

* DECISIONS
  - the three files match byte for byte the files PYTHON_DRILLS/DRILLS/04_WRITE_FILES writes
  - the Tour has no CSV section and no JSON section. =SOURCE/RecordWriter.cpp= writes both formats with =<<=
