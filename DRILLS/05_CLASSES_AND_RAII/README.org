* PROBLEM
Write a class that owns a heap-allocated int array.
Allocate the buffer in the constructor (given a size),
and release it in the destructor.

This is soo the memory is freed automatically
when the object goes out of scope following the RAII pattern.
This should support storing a value at an index (bounds-checked)
and inspecting the contents.

(Modified from link below)
-- GeeksforGeeks, https://www.geeksforgeeks.org/cpp/destructor-for-dynamic-array-in-cpp/
