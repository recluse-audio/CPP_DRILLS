This is README for exercise 3.

* Write a CSV Parser
Assume some "services" dump data from CSV in this kind of format:
```
2026-05-31, login, ryan
2026-05-30,   logout, ryan
2026-04-20,login,Ada
```
- notice the data is "dirty"?

** OBJECTIVE: Provide a set of functions for string manipulation
  These should be backed up by tests.

** REQUIRED FUNCTIONS

```
// Reverse given string
std::string reverse(const std::string& string)
// Remove leading and trailing whitespace
std::string trim(const std::string& string)
// Break on given character 'delim', separate string into vector of smaller strings
std::vector<std::string> split(const std::string& string, char delim)
// Concatenate two strings with a seperator
std::string join(const std::vector<std::string>& parts, const std::string& sep);
// sum of all ints in vector
int sum(const std::vector<int>& vec);
// doubles each element in their current index, modifies ref
void in_place_double(std::vector<int>& vec)
```
